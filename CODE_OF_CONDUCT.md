# Code of conduct

SyncLab follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique ideas rather than people, and help newcomers.
Harassment, personal attacks and discriminatory language are not acceptable in any project space.

Report problems privately to the maintainer via the contact on the GitHub profile of `yeegz`.
Reports are handled confidentially. Maintainers may remove content or contributors that break these rules.
